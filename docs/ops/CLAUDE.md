# ops

## Docs ops 운영 규칙

- docs/ops/context/<작업명>-<YYYYMMDD>/ 는 작업·장애·rollout·handoff 중간 기록 위치다.
- docs/ops/appendix/references/ 는 외부 공식 문서, vendor/API/dashboard 자료 위치다.
- docs/ops/appendix/research/ 는 원문 조사·비교 자료 위치다.
- docs/ops/appendix/troubleshooting/ 은 재발 가능한 문제 해결 절차 위치다.
- docs/ops/appendix/assets/ 는 문서 첨부 이미지, 캡처, 샘플 파일 위치다.
- docs/ops/archive/ 는 stale 문서 격리 위치이며, 다시 만들지 말아야 할 파일명을 원문에 명시한다.
- docs/ops/reverse-engineering/ 은 외부 UI/API/프로토콜 역공학 근거와 traceability 위치다.
- reverse-engineering 문서는 INDEX.md, architecture.md, behavior-spec.md, traceability.md, components/ 골격을 사용한다.
